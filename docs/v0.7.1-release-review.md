# v0.7.1 发布复核

> patch 发布。基线 `0.7.0`（2026-09-20，发布提交 `364515b`）。发布日期 2026-09-22。

## 发布动因

`0.7.0` 之后落地的是一批缺陷修复与发布完整性收口，没有新增产品能力，因此按 semver 取 **patch**。
其中一条是线上回归，构成立即发布的硬理由：认证边界加固把「没有会话 cookie」也判成未知身份，
导致**所有未登录访客**的 AI 问答返回 502、登录态与历史接口返回 500（PR #107）。

## 回滚方案

1. 认证判定（最高优先）：revert PR #107 的两个提交即恢复旧行为，但那会让游客重新拿到 500/502，
   因此只应在 `resolveAuthUser` 引发新的误判时才回滚，且回滚范围应收窄到具体调用点。
2. 版本号与门禁：revert PR #106 即恢复 `0.1.0`；无运行时影响。
3. 内容/链接与 AI 头部加固：各自独立成 commit，可单点 revert。
4. 无迁移，故无需数据库回滚；`git revert` 后重新部署即完成站点回滚，Vercel 亦可直接 promote 上一个生产部署。
