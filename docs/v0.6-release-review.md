### 关账期修复

关账复核暴露并修复了三处真实缺陷：

1. **`fix(deps)` 生产漏洞**：`next@16.3.1` 命中 GHSA-p293-qw3h-jr36 / GHSA-2xp9-vwfh-vxw4（critical Image Optimization RCE），升级到 `16.3.5`；`js-yaml` 通过 `overrides` 固定到修复版；新增 `npm run audit:prod` 并在 CI 的 `npm ci` 后执行。生产依赖审计 `found 0 vulnerabilities`。
2. **`fix(content)` 描述评分前缀 bug**：`titleWords()` 未剥离契约要求的 `NN ·` 序号前缀，把 `01` 当作标题词，制造假 `review`（pass 286 → 修复后 294）。改为复用 `stripTitleOrder`，并加回归测试锁定「带前缀 / 不带前缀评分一致且原 title 保留」。
3. **`fix(content)` 术语匹配子串 bug**：`findTitleTerms()` 未抑制被更长术语包含的短术语，「交易所」同时命中「交易」而要求英文标题额外出现 `trading/trade`，产生 2 处假 `gap`（现为 0）。

R13.23 需要**真实用户**（目标中文学习者）对评论、排行榜的需求与风险的一手研究证据，不能由代码或静态分析替代，也不得用竞品功能清单伪造结论。

- 设计决策已就绪：`docs/social-features-review.md` 给出分层结论（异步分享 ✅ / 公开比较 ❌ / 双向互动 ❌）与 5 条重新评审条件。
- 解除阻塞条件：至少完成一轮目标用户访谈或问卷，产出直接需求证据，并把结论回填到 `docs/social-features-review.md` §5。

### 5.2 章节 README 风险提示缺口 — `BLOCKED_UPSTREAM`

`npm run check:risk-warning`：课程正文 **364/364 通过**；章节导语（README）**40/54 通过**（review 12 / gap 2）。

- 缺口章节（zh/en 各一份）：`crypto-perpetuals`、`financial-statements`、`getting-started`、`industry-research`、`spot`、`stocks`，以及完全缺失的 `technical-analysis`。

### 5.3 内容宪法严格模式 — 人工复核 backlog

`npm run check:constitution -- --strict` 当前 exit 1：高危模式命中 **119** 处、疑似收益承诺 **67** 处。绝大多数是教育语境下的合法引用（如「任何承诺稳赚的策略都应先怀疑」「不要跟单荐股」）。默认 CI 门禁为报告式并通过；严格模式作为人工抽查 backlog，不伪造为「零命中」。

## 6. 部署与回滚

- **部署目标**：Vercel（无 ICP，面向全球中文用户）。构建在仓库根目录执行；`NEXT_PUBLIC_SITE_URL` 供 sitemap / robots / OG 回退。
