### 关账期修复

关账复核及 CI 硬化期间暴露并修复了以下真实缺陷：

1. **`fix(deps)` 生产漏洞**：`next@16.3.1` 命中 GHSA-p293-qw3h-jr36 / GHSA-2xp9-vwfh-vxw4（critical Image Optimization RCE），升级到 `16.3.5`；`js-yaml` 通过 `overrides` 固定到修复版；新增 `npm run audit:prod` 并在 CI 的 `npm ci` 后执行。生产依赖审计 `found 0 vulnerabilities`。
2. **`fix(content)` 描述评分前缀 bug**：`titleWords()` 未剥离契约要求的 `NN ·` 序号前缀，把 `01` 当作标题词，制造假 `review`（pass 286 → 修复后 294）。改为复用 `stripTitleOrder`，并加回归测试锁定「带前缀 / 不带前缀评分一致且原 title 保留」。
3. **`fix(content)` 术语匹配子串 bug**：`findTitleTerms()` 未抑制被更长术语包含的短术语，「交易所」同时命中「交易」而要求英文标题额外出现 `trading/trade`，产生 2 处假 `gap`（现为 0）。
4. **`fix(ui)` 状态残留**：K 线 MA 切换只改显隐会残留 series；回放切换难度/上下文未重载历史窗口会从错误起点开始；搜索会在结果数量不变时漏记去抖后的最近词。三处均补了真实回归测试。
5. **`fix(content)` 风险提示回退**：上游 14 个章节 README 缺少可用风险块时，站点在章节页注入本地化、始终可见的兜底提示；不修改子模块，也不篡改上游覆盖报告。
6. **`fix(ai)` JSONB 持久化**：对话保存接口校验并裁剪消息/sources，`sources` 按 JSONB 写入而非 JSON 字符串，补路由测试覆盖非法 payload 与正常保存。
7. **`fix(db)` 约束与回滚**：新增 `0008_goal_tier_constraints.sql` 归一化并约束日/周目标档位，配套 rollback、Drizzle 镜像和静态 schema 契约测试；回滚不恢复已归一化的历史业务值。
8. **`test(e2e)` 稳定性**：Playwright 使用独立端口，PWA 离线用例先在线导航预热 service worker，消除陈旧 server 与冷启动竞态。
9. **`ci(content)` 假绿与过期报告**：CI 的 heredoc 在顶层写入 `---`，把工作流切成第二份 YAML document，GitHub Actions 在 dry-run 后静默跳过后半质量门禁；改为 `printf` 写入并加契约测试，同时让 CI 在当前提交重生成内容质量报告后再归档。
10. **`refactor(ai)` 弃用运行时**：Next.js 16.3.5 已弃用 Edge Runtime；移除 8 个 AI 路由上的显式配置并统一使用默认 Node.js runtime，增加运行时契约测试。生产构建弃用警告消失，静态页由 465 增至 473。
11. **`chore(test)` 原生配置加载**：将 `vitest.config.ts` 迁移为 `vitest.config.mts`，并用 `import.meta.dirname` 替代 `__dirname`，消除 Vite 对 CommonJS 配置加载方式的迁移提示。
12. **`ci(security)` 凭据扫描门禁**：新增受控与未忽略文件扫描，覆盖常见私钥、平台 token 和硬编码赋值；命中日志不回显疑似值，并增加 CLI 负向测试与 CI workflow 契约测试。
13. **`fix(deps)` 全量依赖清零**：将 LHCI 使用的 Lighthouse/Puppeteer 链通过经验证的 npm overrides 修复，完整审计从 13 项降为 0；CI 增加 `audit:all`，不再只审计生产依赖。
14. **`fix(a11y)` Lighthouse 核心审计清零**：修复窄屏品牌/账户链接名称、引导 CTA 与代码块标签对比度、字号控件可见标签一致性；Lighthouse accessibility 从 91–93 提升到三个代表页面全部 100，并把 CI 阻断线收紧到 100 与三项具体审计零失败。
