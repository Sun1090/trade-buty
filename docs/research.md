# Trade Buty · 市场调研报告

> 调研时间：2026-08-22 · 共六轮 · 结论已互相印证，作为产品立项依据。

## 0. 一句话定位

**全球中文用户的免费中立交易教育平台**：学（分级课程）× 练（真行情图表与回放），对标「中文版 BabyPips × ChartMini」。

---

## 1. 技术选型调研

| 方案 | 定位 | 结论 |
|---|---|---|
| **Next.js** | 全功能 React 框架 | ✅ 选定。P0 就用，避免后期迁移 |
| Astro + React 岛屿 | 内容站首选 | ❌ 纯内容站最优，但本项目 P1 起全是真交互 |
| VitePress | kline-buty 现用 | ❌ 只适合纯文档展示，正是要超越的形态 |

市场共识：2025–2026 内容站是 Astro 的天下，但需要大量服务端交互（账号、进度、AI、实时行情）时 Next.js 是终点栈。前期 bundle 大一点的代价可接受。

## 3. 变现与合规

### 变现路径（BabyPips 验证）

BabyPips 数据：年收入约 $150–200 万、团队 10–17 人。

```
免费内容获客（SEO，29 万+ 反向链接）
   → 券商广告 / Affiliate 返佣
   → 高级课程订阅（$29/月，2026 年起）
```

⚠️ BabyPips 2026 年把一半学园塞进付费墙后引发社区反弹——**免费基础课是信任根基，不过早收费**。

变现优先级：Affiliate > 高阶内容订阅；P0–P3 全程免费。

### 合规红线（中文区前车之鉴）

微淼/启牛/长投被监管和媒体划出的红线：

| 红线 | 依据 |
|---|---|
| ❌ 承诺或暗示收益 | "学完年化 15%" 是被点名批判的典型话术 |
| ❌ 荐股荐基 | 属持牌投顾业务，《证券法》第 160 条 |
| ❌ 券商开户导流 | 财商平台为券商引流被监管通报 |
| ✅ 只做知识普及 | 风险教育、概念教学、骗局识别是安全区 |

kline-buty 知识库天生合规：每篇有风险提示块、数字用虚构数据、不点名未定罪公司、只讲识别方法。**这套内容纪律直接继承为新站的内容宪法。**

### 部署与受众

- **面向大陆用户 + 备案**：金融教育审核趋严，加密篇属灰色地带 → 不选
- **面向全球中文用户（选定）**：Vercel 免备案，定位"中文世界的中立交易教育"，沿用 kline-buty 的部署路线

## 4. AI + 教育趋势

- AI Tutoring 是教育科技融资最高品类（约 $14 亿），RAG 架构已是标配
- Khanmigo 实测：AI 出题使练习量提升 **3.2 倍**，单次讲解成本 **$0.04**
- 关键洞察：**错题驱动的自适应出题**（针对每个学生的薄弱概念无限变体出题）才是 AI 陪学的真正卖点，不是通用聊天问答

→ P3 形态定为「错题驱动的自适应出题 + RAG 检索知识库」，向量检索用 Supabase pgvector（201 篇量级足够，不上独立向量库）。

## 5. 中文用户需求侧

- 知乎"新手如何学炒股"、B站入门教程合集、雪球入门贴——需求旺盛、流量巨大
- 供给全是散装内容（大V 文章、视频合集、问答帖），无系统化 + 可交互的学习产品
- **获客渠道现成**：知乎回答、B站视频、雪球专栏即新手聚集地，冷启动分发路径明确

## 6. 增长打法

- TradingView：直接访问 68% + 自然搜索第二——工具留人，社区锁人
- 教育站案例实测：内容集群（content cluster）策略 6 个月自然曝光 **+2105%**，关键词覆盖 600+
- BabyPips 护城河排序：SEO 内容库 > 论坛社区 > 工具

**增长剧本**：201 篇知识库天然构成 SEO 内容集群（每篇一个长尾词："什么是止损""如何计算盈亏比"）→ 图表工具做外链诱饵 → 社区放最后。
