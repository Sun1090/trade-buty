# v0.7 发布复核

> 日期：2026-09-20 · 范围：v0.6 后累计修复、测试、门禁与依赖可靠性改进
> 版本：`0.7.0` · 迁移/回滚：无数据库迁移、无配置必需项、无破坏性 API/URL 变更

## 1. 发布内容

v0.7 不是功能里程碑，而是把 v0.6 后累积的生产回归修复固化为可追溯版本：

- 剪贴板复制：AI 回答、邮件订阅、代码/链接/里程碑分享均使用统一助手；异步与 `execCommand` 失败都有可见反馈。
- 学习数据：本地进度、错题、回放与测验快照在云端合并前做结构校验；回放训练器补回首轮战绩并拒绝非法难度状态。
- 分享与质量：修复回放分享页把万分比误当百分比的评级错误；补齐课程、K 线图、分享、登录、错题与离线队列回归。
- 安全与可靠性：匿名 AI 写入端点接入按 IP 限流；新增 lockfile 可复现门禁，TypeScript 6.0.3 在 peer 兼容范围内完成升级。
- 可访问性：课程正文、callout 与序号的亮色主题颜色不再沿用暗色硬编码值，CI 使用 axe 做对比度回归。

## 2. 范围外与外部阻塞

以下事项没有凭据或真实外部条件时仍保持阻塞，未伪装为完成：

- Sentry 错误监控与告警需要生产 DSN 和告警通道凭据。
- Supabase 云项目线上 RLS/双设备联调需要云 keys、线上数据与两台真实设备。
- GSC、Bing、Vercel Analytics、PostHog 与冷启动分发需要对应账号、域名权限和人工操作。
- 微信/X/Telegram 的真实抓取渲染需要人工抽查。
- R13.23 评论/排行榜用户研究仍需真实目标用户证据。

## 3. 发布前验证

最终验证以退出码为准，完整命令与结果记录在 `docs/progress.md` 的 v0.7 条目。当前结论：

- lint、typecheck、coverage、E2E、生产 build 均通过。
- 生产依赖与全量依赖审计为 0；lockfile 可用 CI 的 npm 主版本复现。
- 内容、宪法、隐私、SEO、结构化数据、sitemap、移动端与 bundle 门禁通过。
- 254 个测试文件 / 2203 个用例通过；474 个静态页面生成；93 项 Playwright E2E 通过。

## 4. 迁移、风险与回滚

- 数据库：无新迁移，现有 `supabase/rollback/0008_goal_tier_constraints.sql` 仍只覆盖 v0.6 前已有回滚场景。
- 部署：Vercel 构建入口和命令不变；缺 Supabase 或 AI 配置时继续走本地/未配置降级。
- 内容：`content/kline-buty` 子模块指针未变更；知识库 README 风险提示上游缺口仍为报告式 backlog。
- 回滚：应用层回滚为 revert v0.7 release commit 并重新部署；无需数据迁移或缓存特殊清理。
