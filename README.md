# Trade Buty

面向全球中文用户的免费中立交易教育平台：分级课程（学）× 真实行情图表与回放（练）。

- 产品规划：[`docs/plan.md`](docs/plan.md)
- 市场调研:[`docs/research.md`](docs/research.md)

## 快速开始

```bash
git clone https://github.com/Sun1090/trade-buty.git
cd trade-buty
git submodule update --init   # 拉取知识库内容
npm install
npm run dev                   # http://localhost:3000
```

## 技术栈

Next.js (App Router) · TypeScript · Tailwind CSS · 知识库以 git submodule 引用 [kline-buty](https://github.com/sun1090/kline-buty)
